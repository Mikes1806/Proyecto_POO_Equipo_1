# Introducción

## Propósito del Proyecto
El sitio web tiene como objetivo ayudar a los estudiantes a administrar su dinero de manera responsable y visualizando cómo se distribuyen sus ingresos según la regla del 50/30/20:

• **50% Necesidades**: Gastos esenciales (alquiler, comida, transporte).

• **30% Deseos**: Entretenimiento, ocio, compras opcionales.

• **20% Ahorros**: Dinero reservado para metas a corto o largo plazo.

Esta herramienta es ideal para estudiantes que deseen tener un control más claro sobre su situación financiera, evitando deudas innecesarias.


## Objetivos del Proyecto
• Facilitar la organización y seguimiento de gastos e ingresos.

• Promover una cultura de ahorro basada en la regla 50/30/20.

• Proporcionar reportes descargables para análisis financiero.

• Garantizar que la aplicación sea intuitiva y fácil de usar.
